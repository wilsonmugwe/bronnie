# Initial Success Metrics

Exact targets will be defined after discovery.

Potential measures include:

- Average enquiry response time
- Manual processing time per request
- Percentage of requests automatically classified
- Percentage of fields extracted correctly
- Percentage of workflows requiring human intervention
- Number of missed requests
- Appointment booking time
- Invoice processing time
- Automation failure rate
- AI classification accuracy
- Cost per processed request
- Staff time saved
