# BRONNIE Initial Scope

## In Scope for Discovery

- Email-based business requests
- Customer enquiries
- Appointment scheduling
- Invoice and document processing
- Workflow routing
- Human approvals
- External system integrations
- Operational dashboards
- Audit logging
- AI-assisted classification and extraction

## Potential POC Scope

A limited workflow demonstrating:

Incoming request
→ AI classification
→ structured extraction
→ workflow routing
→ business action
→ human approval where required
→ audit trail

## Out of Scope Initially

- Fully autonomous financial transactions
- Payroll
- Autonomous payments
- Complex ERP replacement
- Building a general-purpose AI agent framework
- Mobile applications
- Voice agents
- IoT
- Custom machine-learning model training
- Multi-region AWS architecture
- Enterprise-scale multi-tenancy

These may be reconsidered after the POC.
